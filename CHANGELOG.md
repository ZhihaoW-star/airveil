# Changelog

## 0.7.1 beta

- Keep screen capture active when Start protection or Blur Now takes over a six-second preview. Previously, the preview completion path could stop the new session.
- Regression tests cover preview takeover, normal expiry, and Pause cancellation.
- Add a Simplified Chinese getting-started guide and a structured beta feedback form.

The 0.7.1 beta includes these changes; the earlier 0.7.0 download does not.

## 0.7.0 beta

- First source-available macOS package based on the public-API renderer.
- Simpler English and a three-step setup on the Home page.
- Portable build and test scripts; architecture-labelled release ZIP.
- Privacy documentation, known limits, and a synthetic animated demo.
- Original procedural icon and artwork with included generator.

The blur renderer and head-motion policies are retained from the public lab.
This release does not claim App Store approval or complete hardware coverage.
